# SmolRV64 -- Geekbench 5.4.1 (RISC-V preview), 2026-10-29, fetch windows and a two-level BTB

Board build of fe1bfd05 (github main fe1bfd05): the fetch stream asks the I$ for 16-byte windows from any
halfword (an even and an odd 16-byte bank per way), the predictor steers it with a small L1 BTB in its loop
and an 8K-entry L2 behind it that corrects L1 a cycle later (docs/PLAN-2026-10-28-two-level-btb.md), and the
scheduler's wake-at-select is read the cycle after the issue. WNS +0.001 ns, gate PASS on the 4 GiB board
(login, 900 s of Geekbench, zero faults); Ubuntu over NFS, run alone under `perf stat` (the `td` set, every
counter at 100%); no faults. The run booted the uncommitted tree of the same sources (`rtl=665e3789+`,
content e9e4b1273946), which the gate then stamped as fe1bfd05.
