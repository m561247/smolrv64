# SmolRV64 -- Geekbench 5.4.1 (RISC-V preview), 2026-10-21 (second run), the store queue's port fix

Board build of github main 97ba2c9b: e421e166's FP row with rule D20 -- a store through the LSU's
port (uncached or straddling) leaves the store queue at its last write rather than at its handoff,
and the queue hands one to the port only when none is outstanding. A correctness fix: it was found
by the IW=3 storm lockstep, and GB5's single-core work rarely takes that port. 166.67 MHz, WNS
0.005 ns, gate PASS on the 4 GiB board; Ubuntu over NFS, run alone under `perf stat` (the `td` set,
every counter at 100%); no faults. Multi-core 17 (one core).
