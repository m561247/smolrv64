# SmolRV64 -- Geekbench 5.4.1 (RISC-V preview), 2026-10-20, a load's access in M's cycle

Board build of github main da5d52b3: M presents every translated load to the data cache in the
cycle it fills the load's queue entry, and an older store that blocks the load cancels the access
a cycle later; a D$ hit's load-use latency is 4 cycles (the gate's `chase2`, user mode; 5 before).
166.67 MHz, WNS +0.007 ns, gate PASS on the 4 GiB board; Ubuntu over NFS, run alone under `perf
stat` (the `td` set, every counter at 100%); no faults. Multi-core 17 (one core).

+0.19% against -1.27%. Gaussian Blur is bound by its misses and Machine Learning by the dTLB (the
2026-09-27 profile); why the slices overstate these three is not yet known.
